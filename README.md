# Un respiro, Lale

Un rincón suave para Lale, con cariño de Óscar.

Incluye 210 minihistorias, 210 frases de perspectiva, 120 tarjetas motivacionales, 100 notas personales, diario con gráfica orientativa, jardín interactivo y una pausa de respiración.

La aplicación es pública y no pide registro. Todo el contenido está dentro del HTML y se elige al azar, sin repetir hasta recorrer la selección. Puede descargarse una copia completa desde la página. Los videos externos requieren internet.

El diario se procesa en el navegador. Guardarlo es opcional; las entradas permanecen en el navegador y perfil donde se guardaron. La lectura de palabras es orientativa y puede equivocarse con ironías o contextos.

## Uso local

Abre index.html o lale-offline.html con un navegador. No requiere instalación, compilación, bibliotecas externas ni claves de API.

## Publicación

GitHub Pages publica la raíz de la rama main. Los archivos index.html, lale-offline.html y sw.js forman la aplicación completa. .nojekyll permite servir directamente el sitio estático.
